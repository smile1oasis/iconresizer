# ImageResolutionConverter
Convert Your Game Logos into Multiple Resolutions for App Stores

<B>How to Use:<B>
<OL>
  <LI>Right click on the script and RUN WITH POWERSHELL</LI>
  <LI>Select the Image you want to resize (it will create copies of the original file)</LI>
  <LI>Choose from the provided resolutions or enter custom values (separate by commas or spaces)</LI>
  <LI>Click "Resize Image(s)"</LI>
  <LI>The resized files will be saved in the same folder as the selected image</LI>
</OL>
