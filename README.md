# ImageResolutionConverter
Convert your Game Logos in different resolutions for your app stores
<img width="503" height="608" alt="image" src="https://github.com/user-attachments/assets/1212d3e5-0ca0-4cfe-b078-100a42b7a904" />

<B>How to Use:<B>

Right click on the script and RUN WITH POWERSHELL
Select the Image you want in different sizes (it make copies of the file)
Select provided resolutions or enter custom value (comma or separate by space)
Press Resize Image(s)
Files will be converted to the Selected Image's folder
